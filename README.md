# TrendPulse: What's Actually Trending Right Now

Analysis of YouTube trending videos from the US, GB and IN, for a media-analytics content strategy briefing.

## Dataset
Trending YouTube Video Statistics (Kaggle: datasnaek/youtube-new). This dataset is not my own work. Columns description, tags and thumbnail_link were dropped to keep files small.
